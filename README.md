# Svitlo — power outage schedules for Ukraine

Світло: графік відключень світла з віджетами на головний екран iPhone.

An iOS app with home-screen widgets that shows whether there is power right now, when the next outage starts and the full 24-hour schedule for every group the user follows (home, office, parents…). A small Node.js backend collects schedules for 17 regions of Ukraine from open sources, normalises them into one format and caches them.

```
┌──────────────┐   GET /v1/regions/kyiv/schedule?groups=3.2,1.1   ┌──────────────────┐   planned-outages   ┌──────────────┐
│  iOS app     │ ───────────────────────────────────────────────▶ │  backend (Node)  │ ─────────────────▶ │  Yasno API   │
│  SwiftUI     │ ◀─────────────── normalised JSON ─────────────── │  cache 5 min,    │ ◀───────────────── │  (DTEK)      │
└──────┬───────┘                                                   │  stale on error  │                    └──────────────┘
       │ App Group (UserDefaults)                                  └──────────────────┘
┌──────▼───────┐
│  WidgetKit   │  small / medium / large, dots switch groups (interactive, iOS 17)
└──────────────┘
```

## Repository

| Path | What |
| --- | --- |
| `backend/` | Node 22 + TypeScript API, zero runtime dependencies, `node:test` tests |
| `ios/` | SwiftUI app, WidgetKit extension and unit tests; Xcode project generated by XcodeGen |
| `design/` | Link to the design canvas (light/dark, iOS and Android) |

## Run the backend

Requires Node 22.18+ (runs TypeScript directly, no build step).

```bash
cd backend
npm install          # dev tools only: typescript, @types/node
npm run dev          # demo data on http://localhost:8787
npm start            # live data from Yasno
npm test             # 28 tests
npm run typecheck
```

API:

| Endpoint | Description |
| --- | --- |
| `GET /health` | Liveness and data source |
| `GET /v1/regions` | All regions; `available: false` where no open source exists yet |
| `GET /v1/regions/:region/groups` | Outage groups of a region |
| `GET /v1/regions/:region/schedule?groups=3.2,1.1` | Today/tomorrow slots and the current state per group |

Slots are minutes from Kyiv midnight; `kind` is `off` (confirmed) or `maybe` (possible). Responses carry `ETag` and `Cache-Control`; if Yasno is down the last good data is served with `"stale": true`.

## Data sources

| Regions | Source |
| --- | --- |
| Kyiv, Dnipropetrovsk oblast (DTEK, CEK) | Yasno public API |
| Kyiv oblast, Odesa oblast | [Baskerville42/outage-data-ua](https://github.com/Baskerville42/outage-data-ua) (MIT), copies of DTEK schedules |
| Cherkasy, Chernihiv, Ivano-Frankivsk, Kharkiv, Khmelnytskyi, Lviv, Poltava, Rivne, Ternopil, Zakarpattia, Zaporizhzhia, Zhytomyr | [yaroslav2901/OE_OUTAGE_DATA](https://github.com/yaroslav2901/OE_OUTAGE_DATA), copies of oblenergo schedules |
| Chernivtsi, Donetsk, Kherson, Kirovohrad, Mykolaiv, Sumy, Vinnytsia, Volyn | listed, no open source yet |

Region → source mapping lives in `backend/src/providers/catalog.ts`.

## Run the iOS app

Requires Xcode 16+ and iOS 17+.

```bash
brew install xcodegen
cd ios
xcodegen generate
open Svitlo.xcodeproj
```

1. In **Signing & Capabilities** pick your team for both `Svitlo` and `SvitloWidget` (or set `DEVELOPMENT_TEAM` in `project.yml`).
2. If you change the bundle id, change the App Group `group.com.mykolaturchyn.svitlo` in `project.yml` and `Shared/GroupStore.swift` too.
3. Start the backend (`npm run dev`), run the `Svitlo` scheme on a simulator, add a group, then add the widget to the home screen.

The Debug build talks to `http://localhost:8787`; set the Release URL in `project.yml` (`SVITLO_API_BASE_URL`).

## Features

- Groups by region and outage group, with a name (Дім, Офіс…)
- Today / tomorrow schedule, live status and countdown
- Long-press and drag to reorder (the order is the widget order), swipe right to edit, swipe left to delete with undo
- Local notifications 30 minutes before an outage and when power should return
- Widgets: small and medium show one group and switch with dots, large shows up to four groups
- Light and dark themes from the design tokens

## Roadmap

- Address search to find the group automatically (Yasno address endpoints)
- More regions and providers (oblenergo sites)
- Push notifications from the backend when a schedule changes
- Android app (Kotlin + Glance widgets)

Schedules are published by energy companies and can change during the day; the app shows what the provider published.
